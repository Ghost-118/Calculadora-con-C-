# 🧮 Calculadora Básica en C++

Programa sencillo de consola desarrollado en **C++** que solicita el nombre del usuario y dos números enteros para calcular y mostrar simultáneamente sus operaciones aritméticas fundamentales[cite: 19].

---

## 🚀 Características

- 👤 **Entrada Personalizada:** Solicita y almacena el nombre del usuario mediante un arreglo de caracteres[cite: 19].
- ⚡ **Cálculo Simultáneo:** Procesa e imprime de forma secuencial las siguientes operaciones[cite: 19]:
  - Suma (`N1 + N2`)[cite: 19]
  - Resta (`N1 - N2`)[cite: 19]
  - Multiplicación (`N1 * N2`)[cite: 19]
  - División (`N1 / N2`)[cite: 19]

---

## 🛠️ Tecnologías Utilizadas

- **Lenguaje:** C++[cite: 18]
- **Librerías:** `<iostream>`, `<math.h>`[cite: 19]
